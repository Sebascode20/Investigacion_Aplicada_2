# Conversor de Monedas

Una aplicación de React Native para convertir monedas entre USD y EUR.

## Características

- Conversión de monedas entre USD y EUR.
- Interfaz sencilla y fácil de usar.
- Validación de entradas para evitar errores.
- Resultados precisos con dos decimales.

## Requisitos

- Node.js (versión 14 o superior)
- npm o yarn
- React Native CLI o Expo CLI
